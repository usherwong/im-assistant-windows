# 京安智猎 v0.2.0

这一版在原来的「微信/카카오톡 回复助手」之上，加了 Telegram、"角色档案"、"对话总结"和"中英双语"。

> 说明：这是个人 fork 的版本，不是上游发行版。上游只维护微信那套识别，Telegram 适配和角色功能都在这个 fork 里。

## 安装

1. 解压 `jazl-v0.2.0.zip`（整个 `jazl` 目录一起解，别只拿 exe）；
2. 双击 `jazl.exe`；
3. 打开设置，填两把 key：
   - `JEV_API_KEY`：判断/排序用的（支持 typesafe 直连或 OpenRouter）；
   - `LLM_API_KEY`：起草用的（DeepSeek/OpenAI 兼容/Anthropic/Gemini 都可以）；
4. 打开聊天窗口（微信 / Telegram / 카카오톡），点面板上的「采集」开关。

`config.json`、`roles.json`、`contacts.json` 会生成在 exe 旁边，纯本地。**别放在只读目录**（Program Files），放 `%LOCALAPPDATA%\Programs\jazl` 或任意可写目录。

## 这一版新增

### Telegram 适配
- 会话名从窗口标题取（`zhaomm` 这种前缀不可见字符也能读对），不再把关闭按钮的 `X` 当名字；
- 消息区按"壁纸条纹"定位：整屏都是大卡片的机器人会话也不会塌成一条；
- 面板自动贴到 Telegram 右边（放不下就翻到左边）；
- 填入落点避开附件按钮（原来是点到回形针、弹出选文件）。

### 角色与档案（新的）
- 面板会话行多了「角色与档案」按钮：
  - **我的角色**：以谁的身份说话。每个会话绑定一个角色，改选即绑定，之后一直用它；
  - **对方档案**：姓名/公司/职位/来源/阶段/需求/备注，按会话存。
- 角色档案分四块：
  - `voice`：身份 / 说话方式 / 性格 / 目标 / 边界（每次起草都注入）；
  - `facts`：可回答的事实（住哪、喝什么酒、开什么车…），**只有对方问到时才注入**，带时效和检索别名；
  - `vault`：敏感且不该说的事，**永不进提示词**，只在你自己的面板里看；
  - `constraints`：红线（被问私人生活怎么回避之类），每次注入。
- 档案里没写的事，模型不许编（住址、单位、收入、家人），不知道就反问或说"见面聊"。

### 分场景题库
- 三套题：`亲密关系`（原 7 题）/`职场沟通`/`招聘·挖人`，跟着角色走；
- 职场与招聘多了三题：**承诺成色**（真承诺/客气，热话没细节一律算客气）、**兑现记录**（未承诺→兑现两次以上）、**顾虑状态**（没提/已解决/还开着/又提了/提了又岔开）；
- 面板分数改成"带档位"：`对方投入度 6/9 · 中`，颜色跟着走。

### 对话总结
- 「展开聊天记录」下面一张卡，点「总结」跑一次，五行：进展 / 对方态度 / 我方的牌 / 下一步 / 风险；
- 按需触发（不跟着每条消息自动跑），按会话缓存，有新消息会标"建议重新总结"。

### 中英双语
- 对方说英文：界面候选显示中文，点「填入」/「复制」写进去的是英文；
- 对方说中文：两边相同；
- 中英混用按中文处理；
- 语言由本地按汉字/拉丁字母比例判定，不依赖模型自判。

## 已知限制

- OCR 只认**中文和英文**；其他语言（西语/法语等）读出来会乱码，这类会话别指望能用。韩语走 Windows 语言包那条后端。
- 判断和起草都要联网，各家的 key 得你自己填；国内判断用 typesafe 需要能连上（走系统代理/TUN）。
- 「填入」要求本程序的权限不低于聊天窗口。从某些沙箱/受限环境启动会拿不到输入权限，程序会明确报"光标移不过去"。
- 档案和总结都以**会话名**为键；对方改名会变成新会话（面板里可以改绑）。

## 从上一版升上来

- 之前叫 `jev-chat-windows.exe`，现在叫 `jazl.exe`，界面显示名是「京安智猎」；
- `config.json` 里的 key 和设置可以直接沿用；
- 第一次启动会在 exe 旁边生成 `roles.json`（内置一个虚构的示例角色），想换成自己的直接在档案页改。
